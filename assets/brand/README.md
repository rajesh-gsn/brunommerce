# Brunommerce brand files

## Where the files are

| File | Use |
|---|---|
| `assets/images/brunommerce-logo.png` | Full logo with the wordmark (README banner) |
| `packages/bruno-electron/resources/icons/` | App icons: `mac/icon.icns`, `win/icon.ico`, `png/*.png` |
| `packages/bruno-app/src/assets/brunommerce-icon.png` | Logo shown in the app's title bar and welcome screen |
| `packages/bruno-app/public/favicon.ico` | Browser favicon |
| `docs/brunommerce/` | Images for the project page (`docs/index.html`) |

The icon files are the mascot from the full logo, cropped to a square with rounded corners and resized. They are produced from one master image, so a new logo only needs to be exported to these places again.

## How the logo was made

The logo and the chow-chow mascot were created with **ChatGPT (OpenAI image generation)** by the project owner in October 2026. No artwork from Bruno (its logo is from OpenMoji) or from any other third party was used. The icons are crops and resizes of that image.

AI-generated images may not be protected by copyright in some countries, so the logo is best protected as a trademark rather than by copyright. If the mascot is later redrawn by a designer, replace the files above and record who made it here.

## Usage

- Use the logo to refer to Brunommerce, and keep the "unofficial fork of Bruno" notice wherever it is shown on its own.
- Do not use the Bruno name or Bruno's logo as Brunommerce's own.
- Keep clear space around the icon and do not stretch or recolor it.
